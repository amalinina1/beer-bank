# Пивная копилка

Маленькое приложение на одну страницу: каждый раз, когда хочется пива, смахни кружку.

- **Влево — сдержалась.** В кружку падает монетка (по умолчанию 3 €).
- **Вправо — выпила.** Просто отметка, без монетки.

Сверху показано, сколько сэкономлено за неделю (с понедельника по воскресенье). Ниже — разбивка по дням, итоги прошлых недель и общая статистика. Цену монетки можно поменять внизу страницы.

Отметки хранятся в браузере того устройства, на котором их ставишь (localStorage). На телефоне страницу можно добавить на главный экран, и она будет открываться как приложение.

Всё приложение — это один файл `index.html`, без зависимостей и сборки.
